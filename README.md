# ReviewPulse: Get More Google Reviews

Build a simple, modern SaaS MVP called ReviewPulse for US local businesses.

Goal: help businesses request honest Google reviews from customers after a visit.

MVP ONLY

Create:

Landing page with modern premium design.

Simple business dashboard.

Business profile:

Business name

Google Review URL

"Send Review Request" form:

Customer first name

Customer phone number

Button: "Send WhatsApp Request"

Generate a WhatsApp link with a pre-filled message:
"Hi [Name]! Thanks for visiting [Business Name] today. If you enjoyed your visit, would you mind leaving us an honest Google review? [Google Review URL]"

Clicking the button opens WhatsApp with the message ready to send.

Dashboard shows basic request history:

Customer name

Date

Status

Responsive mobile-first UI.

IMPORTANT

Do NOT build WhatsApp API integration yet.

Do NOT build Google API integration yet.

Do NOT build sentiment/review gating.

Do NOT build complex analytics.

Do NOT build team accounts.

Keep the codebase simple and production-ready.

Use Supabase for database/auth if needed.

Use realistic demo data.

Design should feel clean, modern, premium and trustworthy.

Primary CTA: "Get More Google Reviews"

Pricing: $10/month per location.

Build the MVP, not a full SaaS platform.
